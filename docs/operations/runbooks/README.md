# Runbooks

Procedimentos para incidentes recorrentes em produção/staging.

| Runbook | Sintoma |
|---------|---------|
| [`api-down.md`](./api-down.md) | API não responde, health check falha |
| [`db-lag.md`](./db-lag.md) | Postgres lento ou indisponível |
| [`redis-oom.md`](./redis-oom.md) | Redis sem memória ou inacessível |
| [`worker-stalled.md`](./worker-stalled.md) | Jobs BullMQ não processam |
| [`chain-indexer-lag.md`](./chain-indexer-lag.md) | Depósitos on-chain não creditam |
