## Relação com a engenharia

Este diretório define o "porquê" do produto. Quando uma decisão técnica conflitar com algo aqui:

1. Se o produto está errado, abrir ADR e corrigir o documento.
2. Se a implementação está errada, abrir issue de bug e corrigir o código.
3. **Nunca** deixar o código divergir silenciosamente do spec.
